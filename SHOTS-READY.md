# Screenshot scenes ready for operator capture

Every URL is served from `app/`. Wait for `window.__shotReady === true` before capture. The scenes use only the included boulevard and pier sample images.

1. **1-cover.jpg** — `?shot=cover&layout=hero&grade=sunset&photo=pier&caption=AFTER%20HOURS&subtitle=the%20city%20is%20ours` — window **1920×1080**. Landscape cover, intended as the large judge-sheet image.
2. **2-editor.jpg** — `?shot=editor&layout=nine&grade=neon&photo=boulevard&caption=COAST%20DRIVE` — window **1440×1000**. Editor with a sample photo, controls, and nine-panel preview visible.
3. **3-cover-portrait.jpg** — `?shot=cover&format=portrait&layout=story&grade=duo&photo=boulevard&caption=LAST%20LIGHT` — window **1080×1350**. Portrait cover.
4. **4-sizes.jpg** — `?shot=sizes&layout=four&grade=sunset&photo=pier&caption=AFTER%20HOURS` — window **1600×1000**. Square, portrait, and landscape compositions displayed together.
