# Afterglow Cover Lab

Build a cinematic, multi-panel photo cover in your browser. Choose a layout and color grade, tune each panel's crop, write a headline and neon-script subtitle, then export square, portrait, and landscape PNGs in one step. Your photos stay on your device; the editor works offline.

## Covers, composed by you

Afterglow Cover Lab turns local photographs into original poster art with six panel arrangements, five treatments, repeatable grain, vignette, and editable display type. Start with the included sample photographs or add your own. No game artwork, marks, characters, or game fonts are used.

## Run

Open `app/index.html` in a desktop browser. The app loads only local files and user-selected photos. Use **Export all sizes** to save 1080×1080, 1080×1350, and 1920×1080 PNGs.
